مختبر SPHEREx الطيفي — SPHEREx Spectral Lab

قائمة الأدوات والبرامج واللغات البرمجية المستخدمة في بناء المشروع

ملاحظة: هذا المستند مخصص لنموذج تسليم مسابقة ناسا للتطبيقات الفضائية (NASA Space Apps). يمكن طباعته إلى PDF عبر المتصفح (Ctrl+P → Save as PDF).

1. لغات البرمجة

#اللغةالاستخدام في المشروع
1Python 3.14.3الباك إند (FastAPI)، تحضير البيانات وتوليد المكعب الطيفي الاصطناعي (prepare_data.py)
2TypeScriptواجهة المستخدم الأمامية (React مع typing قوي)
3JavaScriptتشغيل React في المتصفح (عبر ترجمة TypeScript)
4HTML5 + CSS3هيكل وتنسيق الصفحات (مع Tailwind CSS)
5PowerShellتشغيل الأوامر والنصوص على نظام ويندوز

2. الخلفية (Backend — FastAPI)

#الأداة / المكتبةالإصدار (تقريبي)الغرض
6FastAPI0.115+إطار العمل للباك إند وواجهة API RESTful
7Uvicorn0.30+خادم ASGI لتشغيل تطبيق FastAPI
8NumPy2.5.4الحسابات العددية، المكعب الطيفي (cube) بحجم 128×128×102
9SciPy1.18الحسابات العلمية والتكامل
10scikit-learn1.5+كشف الأجسام الشاذة (IsolationForest) للمرشدين
11Astropy7.0+قراءة ملفات FITS والحسابات الفلكية
12Astroquery0.4.9الوصول إلى أرشيف NASA/IPAC IRSA (خطط الربط بالبيانات الحقيقية)
13Pydantic2.8+التحقق من صحة البيانات الواردة والصادرة من API
14python-multipart0.0.9دعم تحميل الملفات عبر API
15SQLite—تخزين أصوات المتطوعين في micro-tasks (الخيار البديل: localStorage)

3. الواجهة الأمامية (Frontend)

#الأداة / المكتبةالإصدار (تقريبي)الغرض
16Vite5.4أداة البناء وخادم التطوير السريع
17React18.3مكتبة واجهة المستخدم التفاعلية
18TypeScript5.6إضافة الكتابة الثابتة (typing) للكود الأمامي
19Tailwind CSS3.4تنسيق الواجهة (ثيم داكن فضائي، دعم RTL للغة العربية، متجاوب مع الموبايل)
20PostCSS + Autoprefixer—معالجة CSS وإضافة البادئات للمتصفحات
21Plotly.js (plotly.js-dist-min, react-plotly.js)2.35رسم الأطياف الطيفية، الخرائط الحرارية، والرسم ثلاثي الأبعاد (3D)
22lucide-react0.469مجموعة الأيقونات المستخدمة في الواجهة
23clsx + tailwind-merge—دمج وإدارة فئات CSS في مكونات React
24Web Audio API— (متصفح)تحويل الطيف الطيفي إلى صوت (spectrum sonification)
25Canvas API— (متصفح)رسم المكعب الطيفي وألوان R/G/B مباشرة في المتصفح

4. البيانات والتخزين

#الصيغة / المصدرالغرض
26.bin (Binary Float32)المكعب الطيفي المضغوط (128×128×102 قناة)
27JSONبيانات التعريف (metadata)، أطياف مرجعية، خرائط الجليد، المرشحين المحسبين مسبقاً
28localStorageتخزين أصوات المتطوعين محلياً في المتصفح للمهمات الجماعية (crowd micro-tasks)
29NASA/IPAC IRSAمصدر البيانات الحقيقية لتلسكوب SPHEREx (مخطط للربط المستقبلي عبر astroquery)
30البيان الاصطناعي (Synthetic / Demo data)مكعب طيفي توليده prepare_data.py للسماح ببناء واختبار الواجهة فوراً، ويظهر بعلامة "بيان تجريبي / اصطناعي" في الواجهة

5. النشر (Deployment — مخطط)

#المنصةالغرض
31Vercelنشر واجهة React (frontend) كموقع סטטי
32Render / Railwayنشر الباك إند FastAPI (backend)
33Docker / docker-composeحزمة تشغيل كاملة للمشروع (خيار بديل للنشر الموحد)

6. المصادر العلمية المعتمدة

  • NASA/IPAC IRSA — أرشيف تلسكوب SPHEREx العام (Spectral Images / Quick Release)
  • SpeX Prism Library — قوالب مرجعية للأقزام البنية
  • Pickles stellar templates — قوالب مرجعية للنجوم
  • EAZY galaxy templates — قوالب مرجعية للمجرات
  • أطياف جليد مفتوحة — خطوط امتصاص H₂O، CO₂، CO من أبحاث مفتوحة
SPHEREx Spectral Lab — NASA Space Apps Project · 기타 synthetic data يُستخدم لغرض التطوير فقط ويُظهر بوضوح كـ "Synthetic / Demo data" في الواجهة.
